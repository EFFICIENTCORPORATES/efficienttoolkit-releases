## [1.0.0] — Initial Public Release

**30+ tools across 5 categories**, fully offline:

- **File Explorer:** Folder Walker, Bulk Create Folders, Bulk Rename Files, Auto Sort Files, Duplicate File Finder
- **Excel & CSV:** Combine CSV, CSV → XLSX, XLSX → CSV, Combine Excel (file/sheets mode), Split Excel by Column, XLS → XLSX, Mail Merge, Combine Text Files
- **PDF Tools:** Split PDF (5 modes), Combine PDF, Sort/Reverse PDF, Encrypt PDF, Decrypt PDF, Word → PDF
- **GST Tools:** GSTR1 JSON → Excel, GSTR2B JSON → Excel, Combine GSTR2A Excel, Combine GSTR2B Excel
- **Reconciliation:** GSTR2A vs Purchase Register (5-stage automated matching)
- **Other Formats:** Merge DOCX Files

First public release — free for life for the CA fraternity.
